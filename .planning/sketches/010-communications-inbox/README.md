# Sketch 010: Communications Inbox

## Design Question
Как организовать ежедневную переписку так, чтобы список клиентов был слева, чат по центру, заказы справа, а поле ответа всегда оставалось снизу?

## How to View
open .planning/sketches/010-communications-inbox/index.html

## Variants
- **A: Баланс** — равновесные три колонки для ежедневной работы.
- **B: Широкий чат** — больше места длинной переписке, компактнее клиенты и заказы.
- **C: Заказы нагляднее** — расширенная правая панель с крупными карточками заказов.

## What to Look For
Сравните читаемость списка клиентов, ширину сообщений и достаточность сведений о заказе. Проверьте закреплённый ввод сообщения и мобильный режим.
