# Sketch 002: Создание заказа

## Утверждённое решение

Вариант A — выезжающая справа боковая панель. Карточка клиента остаётся видимой.

## Обязательные данные

- тип заказа и описание изделия;
- клиент и спортсмен;
- актуальный снимок замеров;
- главное изображение модели с предпросмотром;
- требуемая дата получения;
- цена, валюта и предоплата.

Главное изображение используется как превью в карточке, общем списке заказов, канбане и производственном представлении. До создания заказа изображение можно заменить или удалить.
