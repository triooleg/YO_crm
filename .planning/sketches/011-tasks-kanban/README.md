# Sketch 011: Tasks Kanban

## Design Question

Как совместить настраиваемые колонки, создание карточек из входящих сообщений, фото, цветовые маркеры и сроки так, чтобы доска оставалась наглядной при большом количестве задач?

## How to View

Открыть `.planning/sketches/011-tasks-kanban/index.html`.

## Variants

- **B: Визуальная доска** — крупные фото и более свободная карточка для задач, где модель изделия важнее плотности.
- **C: Компактный контроль ★** — вариант по умолчанию: высокая плотность, короткие строки и быстрый просмотр большого количества задач.

## What to Look For

Сравните, насколько быстро в каждом варианте находятся срочные задачи, различаются источники, читаются фото и метки, а также удобно ли перемещать карточки между этапами.

## Prototype Interactions

- Перетаскивание карточек между колонками.
- Создание карточки из входящего сообщения.
- Добавление обычной задачи.
- Открытие карточки и редактирование описания, срока и цветовых меток.
- Добавление изображения с локальным предпросмотром.
- Быстрое создание административной задачи с назначением администратору.
- Выбор типа задачи и исполнителя, фильтрация персональной загрузки.
- Примеры закупочных задач: нитки, ткани и материалы.
- Переименование, добавление и удаление колонок.
- Поиск и фильтрация по меткам.
