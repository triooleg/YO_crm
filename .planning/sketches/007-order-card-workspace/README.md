# Sketch 007: Полноценная карточка заказа

## Design Question

Как одновременно показать модель, состав, замеры, четыре независимых статуса, оплату, доставку, файлы и историю, сохранив быстрый рабочий ритм?

## How to View

`http://127.0.0.1:8123/.planning/sketches/007-order-card-workspace/index.html`

## Variants

- **A: Единый рабочий экран** — все ежедневные сведения и действия видны без вкладок.
- **B: Сводка и вкладки** — компактная шапка, подробности распределены по темам.
- **C: Модель + управление** — крупная визуальная зона слева, рабочие статусы и операции справа.

## What to Look For

Сравните скорость понимания состояния заказа, количество переключений, удобство группового состава, заметность неоплаты и незаполненной доставки. Переключатель «Индивидуальный / Групповой» работает во всех вариантах.

## Уточнение группового заказа
Для каждого спортсмена непосредственно в его строке отображаются три основных размера: грудь, талия и бёдра. Незавершённые замеры показываются явно, без подстановки общих значений заказа.
