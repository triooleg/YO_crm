# Sketch 004: Парные и групповые заказы

## Design Question

Как сохранить один общий заказ, но быстро видеть каждое изделие, спортсмена, замеры и готовность производства?

## How to View

Откройте `.planning/sketches/004-multi-item-orders/index.html`.

## Variants

- **A: Таблица состава** — самый плотный рабочий вариант для групп из 2–30 спортсменов.
- **B: Карточки позиций** — визуальный вариант, удобный для разных моделей внутри заказа.
- **C: Контроль готовности** — позиции сгруппированы по проблемам и этапам производства.

## What to Look For

Сравните скорость поиска спортсмена, заметность отсутствующих замеров, работу с разными моделями и количество информации на одном экране.
