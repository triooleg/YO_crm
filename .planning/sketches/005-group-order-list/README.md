# Sketch 005: Групповой заказ в общем списке

## Design Question

Как показать масштаб, модели, оплату, замеры и срок группового заказа, сохранив плотность общего списка?

## How to View

Откройте `.planning/sketches/005-group-order-list/index.html`.

## Variants

- **A: Сводная строка** — одна строка той же высоты, что индивидуальный заказ.
- **B: Мини-состав** — внутри строки видны три спортсмена и остаток группы.
- **C: Раскрытие состава** — компактная строка, подробности появляются по стрелке.

## What to Look For

Сравните плотность списка, заметность группового заказа и скорость обнаружения отсутствующих замеров.
