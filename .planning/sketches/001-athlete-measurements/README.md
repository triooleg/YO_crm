# Sketch 001: Спортсмен и замеры

## Утверждённое решение

Вариант A — выезжающая справа боковая панель. Измерения выводятся одним вертикальным списком: название слева, компактное числовое поле справа.

## Правила измерений

- Постоянная нумерация от 1 до 17 согласно инструкции Yoleotard.
- №1, №2, №3 и №15 обязательны.
- Шаг ввода — 0,5 см.
- Значения ростовых стандартов округляются до шага 0,5 см.
- Пресеты роста: 105, 110, 115, 120, 125, 130, 135, 140, 144, 148, 152, 156, 159, 162, 165, 168 и 172 см.
- Из таблицы автоматически подставляются только прямые соответствия: №1 ОГ, №2 ОТ1, №3 ОБ, №4 ДПТ, №5 ДП, №6 ДР, №7 ОЗ, №10 ОШ, №13 ДЮС, №15 ДУГА и №16 ДЮП.
- №8, №9, №11, №12, №14 и №17 не имеют безопасного прямого соответствия в таблице и остаются ручными.
- При ручном вводе ближайший ростовый стандарт рассчитывается по всем заполненным полям, которые имеют соответствие в таблице.
- Применение пресета требует явного клика; ручные значения не перезаписываются автоматически.
