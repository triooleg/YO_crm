# Sketch 001: Спортсмен и замеры

## Design Question

Как сохранить простоту для клиента, который заказывает для себя, и одновременно поддержать родителей, тренеров и клубы с несколькими спортсменами?

## How to View

Открыть `.planning/sketches/001-athlete-measurements/index.html`.

## Variants

- **A: Боковая панель** — карточка клиента остаётся видимой; рекомендованный вариант.
- **B: Внутри карточки** — форма раскрывается непосредственно под спортсменом.
- **C: Пошаговое окно** — мастер из двух коротких шагов.

## What to Look For

Сколько контекста остаётся на экране, насколько быстро можно внести повторные замеры и понятно ли, когда спортсмен совпадает с клиентом.
