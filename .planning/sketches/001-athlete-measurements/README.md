# Sketch 001: Спортсмен и замеры

## Утверждённое решение

Вариант A — выезжающая справа боковая панель. Первый спортсмен автоматически совпадает с клиентом; другой спортсмен добавляется только при необходимости.

## Правила измерений

- Используется постоянная нумерация измерений от 1 до 17 согласно инструкции Yoleotard.
- №1, №2, №3 и №15 — базовые обязательные измерения.
- Остальные поля можно заполнить позднее.
- Значения вводятся в сантиметрах с точностью до 0,1 см.
- Название и номер должны одинаково отображаться в форме, истории и заказе.
