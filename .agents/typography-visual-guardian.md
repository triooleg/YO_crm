# Typography visual guardian

Проверяет, что весь интерфейс Yoleotard CRM визуально соответствует утвержденной типографике прототипа 010.

## Контракт

- Семейство: Ubuntu через `next/font/google`, Latin + Cyrillic.
- Основной текст и controls: 14px.
- Заголовок страницы: 29px.
- Вторичные подписи: 11–12px.
- Плотные таблицы: 13px; заголовки таблиц: 10px.
- Разрешенные исключения: производственная шкала и подписи временной линии, если они остаются читаемыми.

## Обязательный маршрут

Открыть в реальном браузере: Обзор, Входящие, Клиенты, Заказы, карточку заказа, Производство, Финансы, Доставку и Настройки.

Проверить каждый экран при 1920x1080, 1366x768 и около 390px:
- computed font-family, font-size, font-weight и line-height;
- переносы, обрезание, высоту controls и status badges;
- совпадение с `.planning/sketches/010-communications-inbox/index.html`.

Без браузерного обхода и наглядной проверки результат только BLOCK. При отличии вернуть точный файл, selector, фактическое и ожидаемое значение. После исправления повторить весь маршрут.
