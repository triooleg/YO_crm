# Локализация интерфейса

Основной язык Yoleotard CRM — русский.

- Пользовательские строки хранятся централизованно в `apps/web/lib/i18n.ts`.
- Внутренние enum-коды API и базы остаются стабильными английскими
  идентификаторами, а интерфейс показывает русские названия.
- Новые статусы, типы заказов, дисциплины, ошибки, кнопки и пустые состояния
  нельзя добавлять без русской отображаемой подписи.
- Даты и денежные значения форматируются через локаль `ru-RU`.
- Имена клиентов, адреса и сообщения сохраняются в исходном языке без
  автоматического перевода или потери Unicode.

Production web URL: `https://crm.yoleotard.com/`.
