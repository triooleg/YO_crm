# Mantine Phase 8: рабочие контролы раздела «Заказы»

## Объём этапа

В изолированном срезе на общие Mantine-компоненты CRM переведены безопасные
интерактивные элементы страницы «Заказы»:

- кнопки создания заказа, фильтра, настройки столбцов и экспорта;
- поиск заказов с доступной кнопкой очистки и возвратом фокуса;
- сортировка, фильтры, вид спорта и рабочие статусы;
- постоянное сообщение об ошибке;
- окно выбора клиента перед открытием существующей формы заказа.

При открытии выбора клиента фокус сразу устанавливается в поиск, `Escape`
закрывает окно, а фокус возвращается на кнопку «Новый заказ».

Большая форма заказа, быстрая оплата, настройка столбцов и нативный выбор даты
не перестраивались. Для срока сохранён уже работающий нативный date picker.

## Совместимость

Сохранены канонический номер заказа и раскрытие строки, редактирование срока и
вида спорта, создание заказа через выбор клиента, а также независимые статусы.
REST-маршруты и payload остались прежними:

- `PATCH /orders/:id/deadline` с `requiredDeliveryAt`;
- `PATCH /orders/:id/discipline` с `discipline`;
- `PATCH /orders/:id/statuses` с одним изменяемым статусом.

API, Prisma, права, аудит, расчёты денег и правила производства не менялись.

## Проверки

- failing-first source-контракты закрепляют общие Mantine-компоненты и прежние
  API payload;
- целевые web-тесты проверяют номер, срок, вид спорта, статусы, историю и форму;
- Playwright выполняет очистку поиска, открытие и закрытие выбора клиента с
  начальным и возвратным фокусом, раскрытие строки, изменение спорта и срока;
- desktop 1920×1080, laptop 1366×768 и mobile 390×844 проверены без document
  overflow; кадры таблицы, раскрытого заказа и окна выбора клиента сохранены.
- после исправлений повторно выполнены `pnpm db:generate` и полный
  `pnpm quality:check`: tests, typecheck и production builds прошли.

## Следующий этап

Следующий безопасный срез — отдельно перевести окно быстрой оплаты или
настройку столбцов. Полную форму заказа следует мигрировать самостоятельным
этапом из-за большого количества полей и бизнес-контрактов.

Commit, push, версия и deployment в этот этап пока не входят.
