# Mantine Phase 7: компактные уведомления Inbox

## Объём этапа

Этап добавляет первый подтверждённый consumer `@mantine/notifications` только во
«Входящих». Полноширинная зелёная плашка больше не используется для коротких
успешных действий:

- копирование сообщения показывает компактное уведомление справа сверху;
- сохранение ответа как шаблона использует такое же уведомление;
- уведомление ограничено шириной 360 px и закрывается автоматически через 3 секунды;
- оператор может закрыть уведомление раньше доступной кнопкой «Закрыть».

Ошибки копирования, сохранения, отправки и подключения не переведены в
автозакрывающиеся уведомления. Они остаются постоянными и требуют внимания
оператора.

## Совместимость

REST-маршруты, provider delivery, payload шаблона, сообщения, черновики,
авторизация, Prisma и аудит не менялись. Добавлена точная зависимость
`@mantine/notifications@9.6.0`, совпадающая с версиями Mantine Core и Hooks.

## Проверки

- failing-first source-контракты закрепляют пакет, корневой контейнер, оба
  success-сценария и отсутствие старой полосы;
- Playwright проверяет реальное копирование, автозакрытие, доступную кнопку,
  отсутствие horizontal overflow и вид 1920×1080, 1366×768 и 390×844;
- отдельные browser-сценарии проверяют сохранение шаблона и постоянные ошибки
  копирования и сохранения;
- полный `pnpm quality:check` проходит tests, typecheck и production builds.

## Следующий этап

Следующий пункт последовательной Mantine-миграции — раздел «Заказы»: сначала
аудит интерактивных контролов и compatibility-контрактов сроков, вида спорта,
раскрытия заказа и создания нового заказа, затем небольшой изолированный срез с
browser comparison. Массовая перестройка страницы не планируется.

Commit, push, версия и deployment в этот этап пока не входят.
