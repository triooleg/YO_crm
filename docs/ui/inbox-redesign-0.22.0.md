# «Входящие» в YOleotard CRM 0.22.0

## Рабочее пространство

На широком экране список диалогов, переписка и карточка клиента прокручиваются независимо. Границы колонок можно перетаскивать и перемещать стрелками с клавиатуры. Ширины и состояние правой панели сохраняются на устройстве. На экранах до 900 px список и карточка клиента открываются отдельно от переписки.

В строках диалогов используются реальные счётчики, последние сообщения, источники и флаги стран. Фильтр с воронкой открывает параметры заказов. В заголовке чата доступны выбор канала и отдельное меню для спама, разделения объединённых аккаунтов и перехода к внешней переписке.

## Сообщения и редактор

Селектор и значок источника входящего сообщения используют существующее переключение канала с сохранением черновика. E-mail из карточки доступен, когда CRM подтверждает, что по этому адресу можно начать переписку. Полный получатель отображается в редакторе. При изменении адреса сохранённый черновик требует явного подтверждения получателя.

Файлы и фотографии прикрепляются в редакторе. Шаблоны открываются из отдельного меню. Трек-номер, инвойс и таблица мерок находятся в инструментах редактора. Предложение AI управляется одним переключателем. Генерация и отправка требуют отдельных действий оператора.

## Карточка клиента

Вкладки «Клиент», «Заказы», «Задачи», «Заметки» и «Файлы» находятся в правой панели. Сводка доступна через действия карточки. Социальные идентификаторы находятся в дополнительных сведениях.

Карточки заказов используют текущий статус, фактическую оплату, остаток и плановые даты из существующего ответа CRM. Статус и номера отслеживания берутся из CRM. Перевозчик берётся из сохранённых отправлений. Для эскизов используются загруженные модели и проверенные публичные HTTPS-фото из Checkout. Если фото недоступно, карточка показывает заглушку. Номера отслеживания используют ссылки из CRM. История отображает записи из действующей истории действий клиента.
