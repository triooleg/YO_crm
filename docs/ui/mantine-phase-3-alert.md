# Mantine Phase 3: единые уведомления об ошибках

Дата: 2026-09-12. Базовый commit: `f1e8571fa151a8c4578993b2a1fdf26c36d79912`.

## Граница среза

Первый срез третьего этапа добавляет общий `CrmAlert` поверх Mantine `Alert` и
переводит на него ошибки верхнего уровня в разделах «Производство», «Финансы» и
«Задачи». «Входящие», вложенные формы, REST API, Prisma и бизнес-правила не
изменяются.

В тот же локальный release candidate добавлен первый общий интерактивный
`ActionIcon`: крестик очистки используется в верхнем поиске CRM и в поиске
списка «Входящих». Поля остаются связанными прежним состоянием; очистка не
меняет серверный контракт фильтрации и возвращает клавиатурный фокус в поле.

## Контракт

- Ошибка объявляется через `role="alert"` и `aria-live="assertive"`.
- Закрываемый вариант использует русскую подпись «Закрыть уведомление» из
  централизованного словаря.
- Общий compatibility layer сохраняет прежние красный tone, геометрию и
  отступы, но визуальный примитив предоставляет Mantine.
- Наличие обработчика `onClose` определяет появление кнопки закрытия; компонент
  без обработчика остаётся постоянным уведомлением, как раньше.

## Проверки

- Failing-first browser contract подтвердил RED на старом уведомлении и GREEN
  после миграции.
- Playwright проверяет точный русский текст, Mantine-root, доступную кнопку
  закрытия и отсутствие document overflow на 1920×1080, 1366×768 и 390×844.
- Отдельные runtime-сценарии проверяют постоянные ошибки загрузки в «Финансах»
  и «Задачах» и отсутствие у них кнопки закрытия, которой раньше не было.
- Скриншоты трёх размеров просмотрены вручную; уведомление не перекрывает
  производственную шкалу и корректно помещается на мобильном экране.
- Отдельный failing-first visual contract сохранил прежний размер текста 16 px,
  который Mantine без compatibility-правила уменьшал до 12 px.
- Failing-first browser contract для поиска проверяет условную видимость
  крестика, синхронную очистку обоих полей, возврат фокуса и touch-размер 40 px
  в мобильной панели клиентов.
- `pnpm db:generate` и полный `pnpm quality:check` прошли: database 9/9, API
  468/468, web 263/263, все typecheck и production builds. Финальный
  version-aware Playwright-набор после добавления очистки поиска прошёл 27/27.

## Следующий рекомендуемый срез

После отдельного review и выпуска продолжить миграцию однотипных уведомлений в
«Доставке» и вложенных формах, затем перейти к общим `Button` и оставшимся
повторяющимся `ActionIcon`.
