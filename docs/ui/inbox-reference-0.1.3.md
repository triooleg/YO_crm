# «Входящие» — перенос референса, 0.1.3

Референс пользователя: `ChatGPT Image 4 сент. 2026 г., 23_23_15.png`.

## Реализовано

- Верхняя панель с рабочей навигацией, поиском по входящим, переходом к
  непрочитанным и меню профиля. Боковое меню с подписями действует только во
  «Входящих»; другие разделы сохраняют прежнюю геометрию.
- Заголовок внутри списка, значки каналов и реальные счётчики, компактный
  фильтр заказов, аватары, бейджи и превью диалогов.
- Мягкие входящие и фиолетовые исходящие сообщения, аватары возле пузырьков,
  разделители дат, галереи и существующие действия с сообщениями.
- Панель ответа: Ответ AI, перевод, шаблоны, запрос мерок из существующего
  подходящего шаблона, улучшение и сохранение текста как шаблона.
  Автосохранение черновика остаётся на существующем ключе; отдельный путь
  создания дублирующего черновика не добавлен.
- Карточки клиента, следующего действия, заказов, спортсменов и заметок.
  Страна показывается с флагом при распознанном коде, время — по сохранённой
  временной зоне. Ростовой стандарт явно отделён от измеренного роста.

## Границы переноса

Сохранено уточнение пользователя: над списком только значки социальных
каналов и количество. Содержимое не подменяется данными из картинки.
Навигация использует существующие разделы; видеосвязь, несуществующие модули
и неподдерживаемые действия из иллюстрации не имитируются кнопками.
Кнопка запроса мерок выбирает существующий шаблон; при его отсутствии
недоступна. Перевод и AI сохраняют прежнее подтверждение перед отправкой.

- Локальный браузер с перехваченным API: 1920×1080, 1728×960, 1366×768,
  1050×768, 900×768, 720×844, 680×844, 390×844.

- Поиск проверен до фактического query `search=Kristy`, уведомления — до
  `conversationScope=UNREAD`, заказы — до `orderScope=ACTIVE_ORDERS`.
- Редактор высотой 140 px не пересекается с toolbar/shortcuts; Ctrl+Enter
  отправляет через прежний путь в перехваченный тестовый API.
- Галерея и медиапревью/Escape, кнопка создания клиента проверены.
- Для визуальных тестов использованы только локальные фикстуры и SVG;
  клиентам ничего не отправлялось. Фикстуры не входят в production-сборку.

Артефакты в рабочей копии: `output/playwright/`, `output/quality.log`.

`CHAT_HANDOFF.md` после завершения выпуска.
