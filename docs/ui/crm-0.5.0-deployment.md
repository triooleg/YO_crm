## Восстановление и evidence

Для всей попытки принят **roll-forward-only**. Старые source/images сохранены
для evidence; окно отката старых writers не открывалось. После новых валютных
записей старый код небезопасен для редактирования. При сбое — ограничить API,
диагностировать и использовать точный совместимый образ либо проверенный forward
fix; не восстанавливать старую БД поверх новых операций, не удалять схему/историю.
