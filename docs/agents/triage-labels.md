# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer review is required |
| `needs-info` | `needs-info` | More information is required from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and executable by an agent |
| `ready-for-human` | `ready-for-human` | Requires a human-only action or decision |
| `wontfix` | `wontfix` | Will not be implemented |

The mapping is configuration, not permission to create labels or mutate issues.
Tracker writes still require authorization from the current task.
