# Прототипы интерфейса заказов

Три throwaway-варианта страницы заказов, переключаемые через `?variant=A|B|C`.

- A — главный рабочий экран после «Входящих»: плотная таблица в логике KeyCRM и компактный полный разворот заказа с независимыми статусами, изделиями, отдельными актуальными мерками каждого костюма, клиентом, производством, оплатами, доставкой и историей. Связанные рабочие разделы открываются точными контекстными переходами; задачи и клиентские файлы не дублируются без собственных данных заказа. Цвет используется только для смыслового разделения статусов и операционных блоков.
- B — компактная таблица и постоянный инспектор выбранного заказа справа.
- C — фокус-режим: очередь заказов слева, рабочая область заказа справа.

Запуск из корня проекта:

```powershell
python -m http.server 4177 --directory apps/web/prototypes/orders-layouts
```

Открыть выбранный вариант: `http://127.0.0.1:4177/?variant=A`.

Прототип не подключён к API, ничего не сохраняет и не предназначен для production.
